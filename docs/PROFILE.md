# 個体別プロファイル

`profiles/qua-profile.example.json` は記入例です。そのままインストールには使用できません。
対象個体の eMMC CID、純正起動コマンドと引数、元のブートコードのハッシュ、起動用データの LBA とハッシュ、専用領域と保護対象領域を記録します。
`base_env` はバンドルに含める元の 128 KiB 環境データを表します。

個体別プロファイル、環境データ、バックアップ、シリアルログ、接続情報、SSH キーを公開リポジトリや Release に含めないでください。
別個体のプロファイルは使用できません。インストール手順は [setup.md](../setup.md) を参照してください。
